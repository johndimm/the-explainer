Console Logging System Demo

Available Log Labels

The following log labels are available:

  • layout - Layout mode changes and decisions
  • profile - Profile loading and saving
  • storage - localStorage operations
  • responsive - Responsive layout changes
  • divider - Divider position changes
  • general - General app state

Console Commands

Show current logging status:
showLoggingStatus()
Enable logging for a specific label:
setLogging('layout', true)
setLogging('profile', true)
setLogging('storage', true)
Disable logging for a specific label:
setLogging('layout', false)
setLogging('responsive', false)
Enable all logging:
Object.values(LOG_LABELS).forEach(label => setLogging(label, true))
Disable all logging:
Object.values(LOG_LABELS).forEach(label => setLogging(label, false))

Current Default Settings

By default, the following labels are enabled:

  • layout - Layout mode changes
  • profile - Profile loading/saving

To see all available labels, run: console.log(LOG_LABELS)

Example Usage

To debug layout issues, you might want to:

  1. Enable all layout-related logging: setLogging('layout', true)
  2. Enable responsive logging: setLogging('responsive', true)
  3. Enable storage logging: setLogging('storage', true)
  4. Try changing the layout mode in the app
  5. Watch the console for labeled logs
